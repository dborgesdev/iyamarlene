# Diretrizes do projeto
Leia docs/project.md antes de implementar. Preserve identidade, Home e informações verificadas; nunca invente dados empresariais, regras comerciais, atendimentos ou resultados. React 19/TS/TanStack Start/Router/Vite/Tailwind 4, destino Cloudflare Workers. App apenas compõe seções; separar dados, integração e UI. Usar pnpm e preservar pnpm-lock.yaml. Validar pnpm typecheck, test, build, check:deploy e preview local, SSR/404/assets/SEO/acessibilidade. WordPress é autoridade de preço, estoque, sessão, pedidos e pagamentos; nunca cachear dados privados nem expor tokens. Artefatos WordPress exigem homologação antes de instalação. Trabalhar na branch feat/woocommerce-ssr-cloudflare. Não executar commit, push, PR, merge, deploy, upload remoto, DNS, domínio personalizado ou alteração remota WordPress sem solicitação explícita. Preservar a Vercel publicada como contingência.
